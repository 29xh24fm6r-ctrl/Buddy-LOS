# Commercial LOS product baseline

This directory is the lossless behavioral and visual baseline for the Buddy LOS SaaS implementation.

- Source repository: `29xh24fm6r-ctrl/Commercial-LOS`
- Source commit: `9f4d14816938417bd0869ad7b6e0471737495b2a`
- Captured files: 2,928 before this README
- Captured scope: product specification, application source, public assets, package manifest, tests, and operating/certification documents

The baseline is excluded from the Buddy runtime build. Product modules move into the native application only when their data, identity, storage, automation, and integration dependencies have SaaS implementations. A module is not complete merely because its UI compiles.

Do not edit captured files in place. Corrections belong in the native Buddy implementation or in a new explicitly identified source snapshot.
